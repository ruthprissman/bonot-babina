# בונות בבינה

הסקילים של הקורס "בונות בבינה", מאת רות פריסמן ([Clearלי](https://aiclearlyapp.com)).
המאגר מתעדכן לאורך הקורס.

## סקילים

| סקיל | מה הוא עושה | מפגש |
|---|---|---|
| [`plan-my-system`](skills/plan-my-system/SKILL.md) | מראיין אותך, שאלה אחת בכל פעם, ובונה איתך תכנון לוגי למערכת בתשעה שלבים. שומר הכל בקובץ `תכנון המערכת.md` | 1 |

## איך מתקינים סקיל

קודם קוראים אותו: לוחצים על השם בטבלה, וקוראים את הקובץ. סקיל הוא הוראות שהבינה מבצעת בשמך, ולכן לא מתקינים סקיל בלי לקרוא אותו.

אחר כך כותבים ל־Claude Code:

> תתקין לי את הסקיל plan-my-system מהמאגר https://github.com/ruthprissman/bonot-babina לתיקיית הסקילים האישית שלי. לפני שאתה מעתיק, תגיד לי בקצרה מה הסקיל עושה, ותחכה לאישור שלי.

Claude Code יבקש אישור לכתוב בתיקייה `.claude`. זה תקין, מאשרים.

אחרי ההתקנה פותחים תיקייה חדשה וריקה בשם "המערכת שלי", ובשיחה חדשה כותבים:

> אני רוצה לתכנן את המערכת שאני רוצה לבנות לעסק שלי.

אפשר גם להקליד `/plan-my-system`.

## בתוך כל סקיל

- `SKILL.md`: ההוראות לבינה.
- `template.md`: איך נראה הקובץ שהסקיל כותב.
- `example.md`: דוגמה לתכנון מוכן, של עסק בדוי. כל הפרטים בה מומצאים.
